# Predicting residential sale prices in Hudson County, New Jersey

CS 541A · Fall 2026 · Reproducible research comparison

Can public property records improve on a training-period municipality median when predicting later residential sales? The study compares that baseline with ridge regression and a random forest. The development period starts in July 2023, after the dated 2023 assessment snapshot, and the test set covers calendar 2025 by deed date.

## Run the study

Requirements are Python 3.12, Info-ZIP `unzip` with Deflate64 support, and roughly 400 MB of free disk space. The state archives download on the first run. Existing copies can be placed in `data/` or referenced with `--data PATH`.

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python study.py
python make_deliverables.py
```

The study writes aggregate CSVs only. The second command renders figures, `report.pdf`, and `presentation.pptx` from the CSVs. For custom result and delivery folders, pass `--results PATH --output PATH` to the rendering script. New Jersey can replace archives at the same URLs, especially its year-to-date file. Compare the new `sources.csv` to the committed copy before treating a rerun as an exact replication. On systems without Unix shell syntax, set the BLAS environment variable separately if needed.

## Output guide

| Files | Contents |
|---|---|
| `sources.csv`, `archive_coverage.csv`, `monthly.csv` | State URLs, checksums, and deed-month coverage |
| `filter_audit.csv`, `cohort.csv`, `price_audit.csv`, `split.csv` | Eligibility, duplicates, assessment missingness, price range, and temporal split |
| `validation.csv`, `selected.csv` | Fold sizes, settings, and validation metrics |
| `overall.csv`, `intervals.csv` | Final test metrics and paired parcel-bootstrap intervals for model minus median |
| `municipality.csv`, `price_band.csv`, `assessment.csv`, `overlap.csv`, `parcel_scope.csv` | Test diagnostics. Groups below 30 retain only counts. |
| `sensitivity.csv` | Municipality-only fits and refits after excluding overlapping training parcels |

The main unit is an eligible deed transfer; a repeat parcel can contribute more than one transfer. The report defines the estimand, limitations and feature timing. State archive downloads may contain names or other fields unrelated to this study. Raw records and row-level predictions are neither exported nor included.
